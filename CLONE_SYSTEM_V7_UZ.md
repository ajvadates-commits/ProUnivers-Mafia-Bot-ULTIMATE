# Clone System v7

1. Main bot -> /shop -> 🧬 Clone Bot -> Telegram Stars purchase.
2. Purchase gives one clone credit.
3. Main bot -> /clone or Owner -> Clone Bots -> Clone yaratish.
4. User sends a BotFather token in private chat.
5. Token is validated with getMe, encrypted, stored, and runtime is started.
6. Clone owner uses /owner inside the clone.
7. Clone owner can add admins and permissions for that clone.
8. Main owner can start/stop/remove every clone from the main owner panel.
9. Clone cannot buy/create another clone.
10. Required channels and bans are scoped by clone_id.
11. Active clones restart automatically after server restart.
