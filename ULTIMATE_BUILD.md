# ProUnivers Mafia Bot Ultimate v5

Built from the supplied Mafia bot archives. The JavaScript v4 project is the integrated runtime base because it has the broadest owner/admin, game, economy, required-channel, Stars, clone, health and SQLite features. The Python aiogram project is treated as a feature/reference source rather than mixed into the Node runtime.

The `advanced/` layer adds reusable engines for achievements, analytics, anti-cheat, clans, quests, tournaments, moderation, notifications, role balancing, economy, profiles, sessions, events, feature flags, backups and security.

Never commit real `.env` secrets. Configure production credentials separately.
